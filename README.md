# 🚀 MISE EN LIGNE : SITE VITRINE (CDOC Support)

Voici comment envoyer ce projet spécifique sur votre GitHub **cha454** et le mettre en ligne.

## 1. Créer le dépôt sur GitHub
1. Allez sur : [https://github.com/new](https://github.com/new)
2. Nom du dépôt : `site-vitrine`
3. Description : `CDOC Support Informatique - Site Vitrine`
4. Cliquez sur **"Create repository"** (ne cochez rien d'autre).

## 2. Envoyer les fichiers (Méthode Web)
Comme Git n'est pas installé sur ce terminal, la méthode la plus rapide est :
1. Sur la page de votre nouveau dépôt, cliquez sur le lien **"uploading an existing file"**.
2. Allez dans votre dossier `site-vitrine/` sur votre ordinateur.
3. Sélectionnez **TOUT le contenu** du dossier (sauf `node_modules` et `dist`).
4. Glissez-déposez les fichiers sur GitHub.
5. Dans le champ "Commit changes", écrivez : `Initial commit`
6. Cliquez sur **"Commit changes"**.

## 3. Déploiement sur Vercel (Gratuit)
1. Allez sur [Vercel](https://vercel.com) et connectez-vous avec GitHub.
2. Cliquez sur **"Add New"** > **"Project"**.
3. Importez `site-vitrine`.
4. Vercel détectera automatiquement la configuration (Vite).
5. Cliquez sur **"Deploy"**.

---
**Note :** Le SEO, le sitemap et le robots.txt sont déjà configurés pour votre domaine `cdoc-support.com`.
